# cwiczenia

Aplikacja do planowania i prowadzenia treningów: siłownia, kalistenika, bieganie (GPS), pływanie i inne aktywności. PWA na telefon (HTML/CSS/JS), dane w telefonie, bez konta.

- Aplikacja: https://jakubolowniuk-ai.github.io/cwiczenia/
- Dokumentacja: folder [`dokumentacja/`](dokumentacja/) – zasady projektu, funkcjonalność (stan aktualny), model danych, wgrywanie i testy, historia zmian.
